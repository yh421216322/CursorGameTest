# 游戏系统总览

## 📋 项目概述

**项目名称:** Unity 2D 丧尸末日生存游戏  
**开发架构:** QFramework 四层架构  
**开发状态:** 核心系统已完成  
**支持版本:** Unity 2023.2+

## 🎮 核心游戏系统

### 1. 🔬 高级科技系统 (AdvancedTechSystem)
**状态:** ✅ 已完成 (568行)

**核心功能:**
- **4层科技树:** 基础 → 应用 → 高级 → 实验性
- **15+科技节点:** 生产、防御、医疗、能源、军事、研究、特殊
- **研究管理:** 开始、暂停、取消、完成操作
- **动态效率:** 多重修正因子的效率计算
- **研究点数:** 生成速率和累积系统

**科技类别:**
- **生产科技:** 农业改良、机械化生产、自动化制造
- **防御科技:** 防御工事、高级武器、能量护盾
- **医疗科技:** 基础医疗、高级医疗、基因工程
- **能源科技:** 电力基础、可再生能源、核能技术
- **军事科技:** 武器制造、战术训练、特种部队
- **研究科技:** 研究方法、超级计算机、量子计算
- **特殊科技:** 纳米技术、人工智能、终极生存

### 2. 🏗️ 增强建筑系统 (EnhancedBuildingSystem)
**状态:** ✅ 已完成 (923行)

**核心功能:**
- **完整生命周期:** 建造、升级、修复、拆除、运营切换
- **14种建筑类型:** 住宅、生产、防御、高科技建筑
- **智能生产:** 自动资源生成和效率计算
- **工人分配:** 影响建筑效率的人员管理
- **网格建造:** 2x2网格系统，冲突检测

**建筑分类:**
- **住宅类:** 避难所、民房、医疗站、图书馆
- **生产类:** 农田、工坊、采石场、仓库
- **防御类:** 围墙、瞭望塔、大门
- **高科技:** 温室、工厂、实验室、发电厂

### 3. 🛡️ 防御系统 (DefenseSystem)
**状态:** ✅ 已完成 (3862行)

**核心功能:**
- **8种防御塔:** 机枪、火炮、火焰、狙击、榴弹、激光、电磁、冰冻
- **智能目标选择:** 距离、血量、集群优先级算法
- **投射物系统:** 8种弹药类型，物理模拟
- **等级升级:** 1-5级，属性递增
- **实时战斗:** 分层更新机制，性能优化

**防御塔特性:**
- **机枪塔:** 高射速低伤害，成本50，射程8m
- **火炮塔:** 高伤害低射速，成本80，射程12m
- **狙击塔:** 超远程精准，成本100，射程20m
- **激光塔:** 瞬间命中，成本120，射程10m

### 4. 🧟 僵尸系统 (ZombieSystem)
**状态:** ✅ 已完成 (701行)

**核心功能:**
- **多种僵尸类型:** 普通、快速、强力、巨型僵尸
- **AI行为:** 寻路、攻击、群体行为
- **生命周期管理:** 生成、移动、战斗、死亡
- **波次系统:** 难度递增的僵尸波次
- **伤害系统:** 血量管理、伤害计算

### 5. 📦 资源系统 (ResourceSystem)
**状态:** ✅ 已完成 (378行)

**核心功能:**
- **4种基础资源:** 食物、材料、弹药、电力
- **资源生产:** 建筑生产、时间积累
- **消耗管理:** 人口维持、建造消耗、战斗消耗
- **存储管理:** 容量限制、仓库扩展
- **平衡机制:** 生产与消耗的动态平衡

### 6. 🎭 事件系统 (EventSystem)
**状态:** ✅ 已完成 (590行)

**核心功能:**
- **事件总线:** 全局事件通信机制
- **事件类型:** 系统事件、游戏事件、UI事件
- **异步处理:** 非阻塞事件处理
- **优先级队列:** 事件优先级管理
- **错误处理:** 异常事件的容错机制

## 🎯 系统集成关系

### 科技系统 ↔ 其他系统
- **→ 建筑系统:** 解锁高级建筑，提升生产效率
- **→ 防御系统:** 增强防御塔伤害，解锁新塔类型
- **→ 资源系统:** 提升资源生产效率
- **→ 僵尸系统:** 影响僵尸感染率和抗性

### 建筑系统 ↔ 其他系统
- **→ 资源系统:** 生产各类资源
- **→ 防御系统:** 提供建造位置和防御工事
- **← 科技系统:** 接受科技解锁和效率加成
- **→ 僵尸系统:** 提供防御屏障

### 防御系统 ↔ 其他系统
- **→ 僵尸系统:** 攻击和消灭僵尸
- **← 资源系统:** 消耗弹药和材料
- **← 建筑系统:** 依赖建筑提供基础设施
- **← 科技系统:** 接受科技加成

## 📊 性能与优化

### 更新频率设计
```
系统名称            更新间隔    频率    主要任务
─────────────────────────────────────────────────
AdvancedTechSystem    1.0s      1Hz    研究进度更新
                     0.1s     10Hz    研究点数生成
                     5.0s    0.2Hz    效率重计算

BuildingSystem       0.5s      2Hz    建造进度更新
                     1.0s      1Hz    生产更新
                     5.0s    0.2Hz    效率重计算

DefenseSystem        0.1s     10Hz    防御塔更新
                    0.02s     50Hz    投射物更新
                     0.2s      5Hz    目标选择更新

ZombieSystem         0.1s     10Hz    AI行为更新
                    0.05s     20Hz    移动更新

ResourceSystem       1.0s      1Hz    资源计算更新
```

### 内存优化策略
- **对象池管理:** 投射物、僵尸、建筑GameObject复用
- **分帧更新:** 避免单帧计算过载
- **引用缓存:** 减少重复获取系统引用
- **及时清理:** 死亡对象和无效引用的及时释放

## 🔧 开发工具与调试

### 键盘快捷键系统
```
科技系统快捷键:
R - 研究当前选中科技    E - 暂停当前研究
Q - 取消当前研究        F - 快速完成研究
G - 添加1000研究点数

建筑系统快捷键:
1-9 - 建造不同类型建筑   B/V/T - 快速建造
U - 修复所有建筑         I - 升级所有建筑
Ctrl+B/V/T - 批量建造

防御系统快捷键:
Z - 开始防御战斗         X - 结束防御战斗
C - 建造机枪塔           V - 建造火炮塔
```

### 调试命令
- **科技调试:** 解锁所有科技、重置科技树、批量研究
- **建筑调试:** 快速建造、批量操作、立即完成
- **防御调试:** 快速升级、修复所有、清除投射物
- **资源调试:** 添加资源、重置资源、无限资源模式

### UI调试面板
- **实时统计显示:** 各系统状态和性能指标
- **颜色编码:** 绿色(正常)、黄色(警告)、红色(错误)
- **进度条:** 研究进度、建造进度、资源生产进度
- **数据监控:** FPS、内存使用、更新频率

- **资源状态:** 绿色(充足) → 黄色(一般) → 红色(不足)
