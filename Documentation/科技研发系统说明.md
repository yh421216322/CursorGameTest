# 科技研发系统说明文档

## 📋 系统概述

**系统名称:** 高级科技系统 (AdvancedTechSystem)  
**文件位置:** Assets/Scripts/GameScripts/System/AdvancedTechSystem.cs  
**代码行数:** 568行

科技研发系统是丧尸末日生存游戏的核心发展引擎，为玩家提供技术进步的路径，通过研究不同科技来解锁新建筑、提升效率、增强防御能力。

## 🎯 核心功能

### 1. 科技树结构
采用4层递进式科技树设计：

```
基础科技 (Basic) → 应用科技 (Applied) → 高级科技 (Advanced) → 实验性科技 (Experimental)
```

#### 科技层级说明
- **基础科技 (Tier 1):** 游戏初期可研究，成本低，研究时间短
- **应用科技 (Tier 2):** 基于基础科技的实用化技术
- **高级科技 (Tier 3):** 需要多个前置科技，效果显著
- **实验性科技 (Tier 4):** 终极科技，研究成本极高，效果强大

### 2. 科技分类系统

#### 🌾 生产科技 (Production)
- **基础农业:** 提升农田产量20%，解锁温室建筑
- **机械化生产:** 工坊效率+30%，解锁工厂建筑
- **自动化制造:** 所有生产建筑效率+50%，解锁自动化设备

#### 🛡️ 防御科技 (Defense)
- **防御工事:** 围墙血量+50%，解锁高级围墙
- **高级武器:** 防御塔伤害+25%，解锁新塔类型
- **能量护盾:** 建筑获得能量护盾，减少50%伤害

#### 🏥 医疗科技 (Medical)
- **基础医疗:** 医疗站治疗效率+100%，人口健康+20%
- **高级医疗:** 解锁实验室，研究效率+30%
- **基因工程:** 人口抗感染能力+80%，生存能力大幅提升

#### ⚡ 能源科技 (Energy)
- **电力基础:** 解锁发电厂，提供电力资源
- **可再生能源:** 发电厂效率+100%，环保发电
- **核能技术:** 超高效能源，发电厂产量+300%

#### ⚔️ 军事科技 (Military)
- **武器制造:** 弹药生产效率+40%，武器威力+15%
- **战术训练:** 防御效率+25%，战斗协调性提升
- **特种部队:** 解锁精英单位，特殊作战能力

#### 🔬 研究科技 (Research)
- **研究方法:** 研究效率+20%，研究点数生成+30%
- **超级计算机:** 研究效率+60%，可同时进行多项研究
- **量子计算:** 研究效率+150%，解锁终极科技

#### ✨ 特殊科技 (Special)
- **纳米技术:** 所有建筑效率+40%，自我修复能力
- **人工智能:** 自动化管理，资源优化分配
- **终极生存:** 大逃亡协议，游戏胜利条件

### 3. 研究管理系统

#### 研究操作
```csharp
// 开始研究
public bool StartResearch(string techId)

// 暂停研究
public bool PauseResearch()

// 取消研究
public bool CancelResearch()

// 完成研究
```

#### 研究状态
- **未解锁 (Locked):** 前置条件未满足，显示为灰色
- **可研究 (Available):** 满足前置条件，可以开始研究
- **研究中 (Researching):** 正在进行研究，显示进度
- **已完成 (Completed):** 研究完成，效果已生效

### 4. 研究点数系统

#### 点数生成
- **基础生成:** 每0.1秒生成1点研究点数
- **建筑加成:** 图书馆+30%，实验室+80%
- **科技加成:** 研究方法+30%，超级计算机+60%
- **效率修正:** 综合效率影响最终生成速度

### 效率计算系统
```csharp
private float CalculateResearchEfficiency()
{
    float baseEfficiency = 1.0f;
    
    // 建筑加成
    float buildingBonus = GetBuildingResearchBonus();
    
    // 科技加成
    float techBonus = GetTechEffectValue("research_efficiency_bonus", 0f);
    
    // 人员加成
    float staffBonus = GetResearchStaffBonus();
    
    // 综合效率 = 基础效率 × (1 + 各种加成)
    return baseEfficiency * (1f + buildingBonus + techBonus + staffBonus);
}
```
