# 建筑与幸存者系统说明文档

## 一、建筑系统

### 建筑等级分类
建筑分为5个等级，每个等级代表不同的复杂度和效率：
- **1级建筑**：基础设施，快速建造，低效率
- **2级建筑**：改进设施，中等建造时间，中等效率
- **3级建筑**：高级设施，较长建造时间，高效率
- **4级建筑**：专业设施，长建造时间，专业化功能
- **5级建筑**：顶级设施，最长建造时间，最高效率

## 二、幸存者属性系统

### 1. 核心属性体系
幸存者不再有固定职业，而是拥有6个核心属性，每个属性影响不同的工作效率：

#### 生产力 (Production)
- 范围：0-100
- 影响：农业生产、物资制造、资源采集效率
- 高生产力幸存者适合：农场、工坊、工厂等生产建筑

#### 战斗力 (Combat)
- 范围：0-100
- 影响：防御建筑效率、战斗伤害、生存能力
- 高战斗力幸存者适合：防御塔、瞭望塔、巡逻任务

#### 技术力 (Technology)
- 范围：0-100
- 影响：高级建筑操作、设备维护、自动化效率
- 高技术力幸存者适合：自动化工厂、重型设备、陷阱维护

#### 医疗力 (Medical)
- 范围：0-100
- 影响：治疗效率、健康维护、疫病防控
- 高医疗力幸存者适合：医疗站、医院、健康管理

#### 科研力 (Research)
- 范围：0-100
- 影响：科技研发速度、新技术解锁、创新能力
- 高科研力幸存者适合：研究所、科技中心、技术开发

#### 探索力 (Exploration)
- 范围：0-100
- 影响：资源发现、危险预警、侦察效率
- 高探索力幸存者适合：拾荒站、瞭望塔、外出任务

#### 领导力 (Leadership)
- 范围：0-100
- 影响：团队效率加成、士气提升、管理能力
- 高领导力幸存者适合：指挥中心、大型设施管理

### 2. 属性等级划分
- **0-20**：新手级 - 基础能力
- **21-40**：熟练级 - 有一定经验
- **41-60**：专业级 - 专业水准
- **61-80**：专家级 - 高级专家
- **81-100**：大师级 - 顶级能力

### 3. 幸存者类型示例
#### 全能型幸存者
- 各属性均衡发展（40-60）
- 适合多种工作，但无特殊专长

#### 专精型幸存者
- 某项属性极高（80+），其他属性较低
- 在专业领域效率极高

#### 双专精型幸存者
- 两项属性较高（60-80），其他属性中等
- 适合复合型工作

### 4. 效率计算公式
**工作效率 = 基础效率 × (1 + 主要属性加成 + 次要属性加成 + 状态修正)**

- 基础效率：100%
- 主要属性加成：对应属性值 × 1%（如生产力70 = +70%）
- 次要属性加成：相关属性值 × 0.5%（如技术力辅助生产）
- 状态修正：健康、士气、疲劳等因素

### 5. 属性成长系统
- 幸存者通过工作获得经验
- 经验可用于提升对应属性
- 不同工作类型提升不同属性
- 高等级属性提升需要更多经验

## 三、系统特点

### 1. 灵活的建筑升级路径
- 从简单到复杂的5级建筑体系
- 玩家可根据需求选择建造等级
- 高级建筑需要高属性幸存者操作

### 2. 个性化的幸存者培养
- 属性系统比职业系统更灵活
- 玩家可自定义幸存者发展方向
- 不同属性组合创造独特价值

### 3. 策略性的资源分配
- 建筑等级影响资源投入和产出
- 幸存者属性匹配决定效率
- 平衡发展vs专精发展的策略选择

### 4. 渐进式的游戏体验
- 从低级建筑开始，逐步解锁高级设施
- 幸存者属性随游戏进程成长
- 提供长期的发展目标和成就感

## 四、物资系统

### 1. 基础物资（原材料）
#### 食物 (Food)
- 类型：基础物资
- 用途：维持幸存者生存，影响士气和健康
- 消耗：每个幸存者每天消耗2-3单位食物
- 获取方式：
  - 简易农田：1-2单位/小时（直接产出）
  - 农场：3-5单位/小时（直接产出）
  - 大型农场：8-12单位/小时（直接产出）
  - 拾荒站：偶尔发现罐头食品（直接获取）
- 储存：需要建造仓库，否则容易腐烂

#### 材料 (Materials)
- 类型：基础物资
- 用途：建造和升级建筑的主要资源
- 获取方式：
  - 拾荒站：2-4单位/小时（直接收集）
  - 采石场：3-6单位/小时（直接开采）
  - 精炼厂：废料回收，2-3单位/小时（回收处理）
- 储存：相对稳定，不易损坏

#### 水 (Water)
- 类型：基础物资
- 用途：维持生存，工业用水，清洁卫生
- 消耗：每个幸存者每天消耗1-2单位水
- 获取方式：
  - 水井：2-4单位/小时（直接产出）
  - 雨水收集器：天气依赖，0-6单位/小时
- 储存：需要专门的水箱

#### 废料 (Scrap)
- 类型：基础物资
- 用途：回收利用，制造材料和零件
- 获取方式：
  - 拾荒站：4-8单位/小时（直接收集）
  - 建筑拆除：获得部分废料
- 储存：占用空间大，需要分类

#### 有机物 (Organic Matter)
- 类型：基础物资
- 用途：制造生物燃料，肥料，食物加工
- 获取方式：
  - 农场：副产品，1-2单位/小时
  - 食物腐烂：自然产生
  - 人员排泄物：每人每天0.5单位
- 储存：容易腐烂，需要快速处理

### 2. 成品物资（制造品）
#### 弹药 (Ammunition)
- 类型：成品物资
- 用途：防御建筑作战，幸存者武装
- 制造消耗：2材料 + 1废料 = 5弹药
- 制造地点：
  - 简易工作台：1-2单位/小时
  - 工坊：3-5单位/小时
  - 军工厂：8-12单位/小时
  - 自动化工厂：15-20单位/小时
- 储存：需要专门的弹药库，注意安全

#### 医疗用品 (Medical Supplies)
- 类型：成品物资
- 用途：治疗伤员，预防疾病，提升健康
- 制造消耗：1材料 + 1有机物 + 1水 = 3医疗用品
- 制造地点：
  - 急救站：0.5-1单位/小时
  - 医疗帐篷：1-2单位/小时
  - 医疗站：3-5单位/小时
  - 高级医院：8-12单位/小时
  - 超级医疗中心：15-20单位/小时
- 储存：有保质期，需要适当环境

#### 工具 (Tools)
- 类型：成品物资
- 用途：提高工作效率，建筑维护，设备修理
- 制造消耗：3材料 + 2废料 = 2工具
- 制造地点：
  - 简易工作台：0.5-1单位/小时
  - 工坊：2-3单位/小时
  - 自动化工厂：5-8单位/小时
- 储存：相对稳定，需要防锈

#### 燃料 (Fuel)
- 类型：成品物资
- 用途：车辆运行，发电机燃料，取暖
- 制造消耗：2有机物 + 1水 = 3燃料（生物燃料）
- 制造地点：
  - 精炼厂：2-4单位/小时
  - 自动化工厂：6-10单位/小时
- 获取方式：
  - 探索获取：在废弃加油站寻找
- 储存：易燃易爆，需要专门储存

#### 电子元件 (Electronics)
- 类型：成品物资
- 用途：制造高科技设备，自动化系统
- 制造消耗：2材料 + 3废料 + 1稀有金属 = 1电子元件
- 制造地点：
  - 工坊：0.2-0.5单位/小时
  - 电子工厂：2-4单位/小时
  - 科技中心：1-2单位/小时（研发新型）
- 获取方式：
  - 废墟回收：从废弃电器中拆解
- 储存：怕潮湿，需要干燥环境

### 3. 高级资源
#### 能源 (Energy)
- 类型：特殊资源
- 用途：高级建筑运行，自动化设备供电
- 生产消耗：
  - 发电机：2燃料 = 10能源/小时
  - 太阳能板：0消耗 = 5-15能源/小时（天气依赖）
  - 风力发电：0消耗 = 8-20能源/小时（风力依赖）
  - 核能反应堆：1稀有金属 = 100能源/小时
- 储存：需要电池系统，否则即产即用

#### 科研点数 (Research Points)
- 类型：特殊资源
- 用途：解锁新科技，升级建筑配方
- 生产方式：
  - 研究台：1-2点/小时
  - 简易研究角：0.5-1点/小时
  - 小型实验室：2-3点/小时
  - 研究所：5-8点/小时
  - 科技中心：10-15点/小时
  - 超级医疗中心：医疗科研，3-5点/小时
- 消耗：解锁科技时一次性消耗

#### 稀有金属 (Rare Metals)
- 类型：特殊资源
- 用途：建造高级建筑，制造精密设备
- 获取方式：
  - 深度挖掘：需要高技术力幸存者，采石场升级功能
  - 废墟探索：危险但收益高，探索任务
  - 贸易交换：与其他幸存者群体交易
  - 电子设备拆解：从高级电子设备中提取
- 储存：珍贵资源，需要安全储存

### 4. 制造配方系统
#### 基础制造配方
- **弹药制造**：2材料 + 1废料 → 5弹药（工作台级别）
- **医疗用品**：1材料 + 1有机物 + 1水 → 3医疗用品
- **工具制造**：3材料 + 2废料 → 2工具
- **生物燃料**：2有机物 + 1水 → 3燃料

#### 高级制造配方
- **电子元件**：2材料 + 3废料 + 1稀有金属 → 1电子元件
- **高级弹药**：3材料 + 1电子元件 → 8高级弹药
- **高级医疗用品**：2材料 + 1有机物 + 1电子元件 → 5高级医疗用品
- **精密工具**：4材料 + 1电子元件 + 1稀有金属 → 3精密工具

#### 回收配方

- **有机物堆肥**：3有机物 → 1肥料（提高农场产量）
- **电子设备拆解**：1废弃电子设备 → 2废料 + 0.1稀有金属

### 5. 物资管理机制
#### 储存系统
- **基础仓库**：储存100单位基础资源
- **专业仓库**：储存特定类型资源，容量200单位
- **冷藏库**：延长食物保质期，减少50%腐坏速度
- **弹药库**：安全储存弹药，防止爆炸，容量150单位
- **地下储藏室**：大容量储存，500单位，防护性强
- **水箱**：专门储存水资源，容量80单位
- **燃料罐**：安全储存燃料，防火防爆，容量100单位

#### 物资腐坏与损耗
- **食物腐坏**：无冷藏设施时，食物每天损失5-10%
- **有机物腐烂**：3天内必须处理，否则100%损失
- **设备老化**：电子元件和医疗用品会随时间损耗，每月2-5%
- **弹药受潮**：潮湿环境下弹药效果降低20%
- **燃料挥发**：燃料储存不当会缓慢损失，每月1-3%
- **工具磨损**：使用过程中逐渐损耗，需要维护

#### 物资交易系统
- **内部调配**：不同建筑间的资源分配
- **紧急征用**：危机时刻强制调用储备
- **废料回收**：将损坏物品回收为材料
- **资源转换**：某些建筑可以转换资源类型
- **对外贸易**：通过贸易中心与其他势力交换资源

### 5. 科研系统机制
#### 科研点数获取
- 研究台：1-2点/小时
- 简易研究角：0.5-1点/小时
- 小型实验室：2-3点/小时
- 研究所：5-8点/小时
- 科技中心：10-15点/小时
- 超级医疗中心：3-5点/小时（医疗科研）

#### 科研加速机制
- **高属性研究员**：科研力80+的幸存者，研究速度+50%
- **多人协作**：多个研究员同时工作，效率叠加
- **设备升级**：高级研究设备，基础效率+25%
- **跨学科合作**：不同科技树同时研究，互相促进+15%

#### 科研失败与重试
- **研究失败率**：复杂科技有5-15%失败率
- **失败惩罚**：损失50%科研点数，需要重新研究
- **失败原因**：设备不足、人员能力不够、资源短缺
- **降低失败率**：提升设备等级、培养专业人才

#### 科技树互动
- **前置科技**：必须完成前置科技才能研究后续科技
- **科技协同**：某些科技需要多个科技树的前置条件
- **科技冲突**：某些科技路线互相排斥，需要选择
- **科技融合**：高级科技往往需要多学科知识融合
