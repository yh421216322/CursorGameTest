# 生存游戏系统使用说明

## 概述

本系统基于QFramework四层架构设计，提供了完整的建筑、科技、资源和制造管理功能。系统采用配置驱动的设计，方便扩展和维护。

## 系统架构

### 核心系统
- **ConfigSystem**: 配置管理系统，负责加载和管理所有游戏配置
- **ResourceSystem**: 资源管理系统，处理资源的获取、消耗和存储
- **BuildingSystem**: 建筑管理系统，处理建筑的建造、运行和维护
- **TechSystem**: 科技研究系统，管理科技树和研究进度
- **CraftingSystem**: 制造系统，处理物品制造和配方管理
- **SurvivorSystem**: 幸存者管理系统，处理属性和工作分配

### 数据模型
- **ResourceType**: 资源类型枚举和配置
- **BuildingType**: 建筑类型和配置数据
- **TechType**: 科技类型和研究数据
- **SurvivorAttributeType**: 幸存者属性系统

## 快速开始

### 1. 系统初始化

```csharp
// 在游戏启动时，QFramework会自动初始化所有系统
// ConfigSystem会在初始化时加载所有配置数据
```

### 2. 基础资源操作

```csharp
// 获取资源系统
var resourceSystem = this.GetSystem<ResourceSystem>();

// 添加资源
resourceSystem.AddResource(ResourceType.Materials, 1000);
resourceSystem.AddResource(ResourceType.Food, 500);

// 检查资源
int materials = resourceSystem.GetResourceAmount(ResourceType.Materials);
bool canAfford = resourceSystem.CanAfford(costs);

// 消耗资源
resourceSystem.ConsumeResources(costs);
```

### 3. 建筑管理

```csharp
// 建造建筑
this.SendCommand(new AddBuildingCommand("farm_1", position));

// 获取建筑信息
var buildingSystem = this.GetSystem<BuildingSystem>();
var building = buildingSystem.GetBuilding(buildingId);

// 分配工人
buildingSystem.AssignWorker(buildingId, workerId);

// 升级建筑
buildingSystem.UpgradeBuilding(buildingId);
```

### 4. 科技研究

```csharp
// 开始研究
this.SendCommand(new StartResearchCommand("agriculture_1", researchBuildingId));

// 检查科技状态
var techSystem = this.GetSystem<TechSystem>();
var state = techSystem.GetTechState("agriculture_1");
bool completed = techSystem.IsTechCompleted("agriculture_1");

// 添加科研点数
techSystem.AddResearchPoints(100);
```

### 5. 物品制造

```csharp
// 开始制造
this.SendCommand(new StartCraftingCommand("craft_tools", workshopId, 5));

// 获取可用配方
var craftingSystem = this.GetSystem<CraftingSystem>();
var recipes = craftingSystem.GetAvailableRecipes(buildingId);

// 检查制造任务
var tasks = craftingSystem.GetActiveCraftingTasks();
```

## 配置管理

### 新增建筑类型

1. 在`ConfigSystem.CreateProductionBuildings()`中添加新建筑：

```csharp
AddBuildingConfig("new_building_id", "新建筑名称", "建筑描述", 
    BuildingCategory.Production, BuildingLevel.Level1,
    buildCosts, buildTime, requiredTechs, maxWorkers, productions);
```

2. 或使用配置编辑器创建ScriptableObject配置文件

### 新增科技

1. 在`ConfigSystem.CreateSurvivalTechs()`等方法中添加：

```csharp
AddTechConfig("new_tech_id", "新科技名称", "科技描述",
    TechTree.Survival, TechTier.Tier1,
    researchCost, researchTime, prerequisites, unlockedBuildings);
```

### 新增制造配方

1. 在`ConfigSystem.LoadCraftingRecipes()`中添加：

```csharp
AddCraftingRecipe("new_recipe_id", "新配方名称", "配方描述",
    outputType, outputAmount, inputCosts, craftingTime, 
    requiredTechLevel, requiredBuildings);
```

### 新增资源类型

1. 在`ResourceType`枚举中添加新类型
2. 在`ConfigSystem.LoadResourceConfigs()`中添加配置：

```csharp
AddResourceConfig(ResourceType.NewResource, "新资源", "资源描述",
    ResourceCategory.BasicMaterial, canDecay, decayRate, maxStack);
```

## 事件系统

系统使用QFramework的事件系统进行通信：

```csharp
// 监听事件
this.RegisterEvent<BuildingConstructionCompletedEvent>(OnBuildingCompleted);
this.RegisterEvent<TechCompletedEvent>(OnTechCompleted);
this.RegisterEvent<CraftingCompletedEvent>(OnCraftingCompleted);

// 发送事件
this.SendEvent(new BuildingConstructionCompletedEvent 
{ 
    BuildingId = buildingId, 
    ConfigId = configId 
});
```

## 常见问题

### Q: 如何添加新的建筑类型？
A: 在ConfigSystem中添加配置，或使用配置编辑器创建ScriptableObject。

### Q: 科技前置条件如何设置？
A: 在TechConfig的Prerequisites列表中添加前置科技ID。

### Q: 如何实现建筑升级？
A: 使用BuildingUpgrade配置定义升级路径和消耗。

### Q: 资源腐坏如何处理？
A: 在ResourceConfig中设置CanDecay和DecayRate，系统会自动处理。

### Q: 如何优化大量建筑的性能？
A: 使用分批更新、LOD系统和对象池等优化技术。
