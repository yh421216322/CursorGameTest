# 增强建筑系统文档

## 系统概述

增强建筑系统是丧尸末日生存游戏的核心基础设施管理系统，负责建筑的建造、升级、维护和生产管理。系统采用QFramework架构，实现了完整的建筑生命周期管理。

## 核心功能

### 1. 建筑管理
- **建造管理**: 位置检测、资源验证、建造进度跟踪
- **升级系统**: 多等级升级，效率提升，成本递增
- **维护修复**: 血量管理，性能衰减，修复机制
- **拆除回收**: 材料返还，空间释放

### 2. 生产系统
- **资源生产**: 食物、材料、弹药、电力生产
- **效率计算**: 工人分配、科技加成、血量影响
- **生产周期**: 不同建筑类型的生产间隔
- **自动收集**: 定时生产，资源自动添加

### 3. 建筑类型

#### 住宅类建筑
- **避难所 (Shelter)**: 基础住所，+5人口容量，+5士气
- **民房 (House)**: 高级住所，+10人口容量，+10士气
- **医疗站 (MedicalStation)**: 治疗伤病，+15士气，2治疗率
- **图书馆 (Library)**: 提升研究，+30%研究效率，+20士气

#### 生产类建筑
- **农田 (Farm)**: 食物生产，3食物/8秒，需要2工人
- **工坊 (Workshop)**: 弹药制造，2弹药/10秒，需要3工人
- **采石场 (Quarry)**: 材料开采，4材料/12秒，需要4工人
- **仓库 (StorageDepot)**: 增加存储，+100全资源存储

#### 防御类建筑
- **围墙 (Wall)**: 基础防御，+5防御值，100耐久度
- **瞭望塔 (WatchTower)**: 早期预警，10检测范围，+8防御
- **大门 (Gate)**: 可控入口，+15防御值，可开关控制

#### 高级建筑（需科技解锁）
- **温室 (Greenhouse)**: 高效农业，6食物/6秒，需"高级农业"
- **工厂 (Factory)**: 大规模生产，8弹药/7秒，需"机械化生产"
- **实验室 (Laboratory)**: 科研设施，+80%研究效率，需"高级医疗"
- **发电厂 (PowerPlant)**: 电力供应，20电力/5秒，需"可再生能源"

```csharp
    // 信息查询
    List<BuildingData> GetAllBuildings();

    float GetBuildingEfficiency(int buildingId);
}
```

### 核心算法

#### 效率计算
```
建筑效率 = 血量效率 × 工人效率 × (1 + 科技加成)
- 血量效率 = 当前血量 / 100
- 工人效率 = 分配工人数 / 最大工人数
- 科技加成 = 相关科技的累计加成
```

#### 生产周期
- **农田**: 8秒/次，3食物，受农业科技影响
- **工坊**: 10秒/次，2弹药，受生产科技影响
- **采石场**: 12秒/次，4材料，基础生产
- **发电厂**: 5秒/次，20电力，高频生产

### 更新机制
- **建造进度**: 0.5秒间隔更新
- **生产更新**: 1秒间隔更新
- **效率重计算**: 5秒间隔更新

## 游戏平衡

### 建造成本设计
| 建筑类型 | 材料成本 | 建造时间 | 最大等级 |
|---------|---------|---------|---------|
| 避难所 | 20 | 3秒 | 3 |
| 农田 | 25 | 4秒 | 4 |
| 工坊 | 40 | 6秒 | 3 |
| 围墙 | 15 | 2秒 | 3 |
| 温室 | 80 | 10秒 | 4 |
| 工厂 | 120 | 15秒 | 4 |

### 生产平衡
- **食物需求**: 每人每天消耗3-5食物
- **弹药消耗**: 防御战斗每次消耗1-3弹药
- **建材需求**: 建造和升级主要消耗
- **电力用途**: 高级建筑运营需求

### 科技依赖
- **基础建筑**: 无科技要求，游戏开始即可建造
- **中级建筑**: 需要对应的基础科技
- **高级建筑**: 需要进阶科技，解锁强力功能
- **特殊建筑**: 需要多个科技组合解锁

## 操作控制

### 键盘快捷键
- **数字键1-9**: 建造不同类型建筑（鼠标位置）
- **B键**: 快速建造避难所
- **V键**: 快速建造农田
- **T键**: 快速建造工坊
- **U键**: 修复所有建筑
- **I键**: 升级所有建筑

### 批量操作
- **Ctrl+B**: 批量建造5个农田
- **Ctrl+V**: 批量建造3个工坊
- **Ctrl+T**: 批量建造10个围墙

### 建造模式
1. 点击建筑按钮进入建造模式
2. 移动鼠标查看建造位置预览
3. 左键点击确认建造
4. 右键或ESC取消建造模式

## UI显示系统

### 建筑统计面板
- **建筑总数**: 显示已建造建筑数量
- **运营状态**: 显示正常运营的建筑比例
- **类型分布**: 住宅、生产、防御建筑数量
- **生产统计**: 实时显示各类资源生产速度

### 颜色编码
- **绿色**: 高效运营状态（80%以上效率）
- **黄色**: 正常运营状态（50-80%效率）
- **红色**: 低效运营状态（50%以下效率）
- **灰色**: 停用或损坏状态

### 视觉反馈
- **建造中**: 半透明显示，表示未完成
- **损坏状态**: 红色调，提醒需要修复
- **停用状态**: 灰色显示，表示非运营
- **等级显示**: 建筑大小随等级变化
